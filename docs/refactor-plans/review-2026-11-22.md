Each item is a self-contained session. Nothing here is started.

## Remove the dead API client surface

**Why:** the Go uploader is gone, but the feed, tokens and version gate remain and show nothing to users.
**Where:** `src/app/Http/Controllers/Api/*`, `AddonFeedService`, `RequireClientVersion`, `ledger.min_client_version`, `ledger.addon.*` feed limits, Settings tokens, `User::issueIngestToken`, `IssuesIngestToken` trait (one user left), `uploads.source = 'uploader'`; in the addon `Data.lua` reader, `Panel.lua`, `Alerts.lua` and tooltips; `addon/tests/fixtures/Data.lua`.
**Approach:** decide first: remove the whole feed and token path as a unit, or keep it and document a revival path. Removal needs a migration for `uploads.source` and the tokens table use, test and privacy/export copy updates.
**Risks:** the addon's in-game panel and alerts are advertised nowhere now, but users may still have the old feed file; an API for third-party clients may be wanted later.
**Scope:** in: API, tokens, feed, addon feed reader. Out: manual upload, addon recorder.

## Finish the theme-token migration

**Why:** two theming systems coexist: CSS variables (`--surface`, `--text`, `--danger`...) back `.card`/`.btn`/`.seg`/`.data-table`, while views still use `text-gray-* dark:text-gray-*`. Palette hex values are copied in `tailwind.config.js`, the `:root`/`.dark` blocks and `STYLE_GUIDE.md`.
**Where:** `src/resources/css/app.css`, `src/tailwind.config.js`, ~165 `dark:` uses in views, `<x-money>`/`<x-pct>`/`<x-chip>` colour maps, `STYLE_GUIDE.md`.
**Approach:** make Tailwind the single palette source with the variables derived from it, move views to semantic classes, stop retuning `amber-600`/`green-*`/`red-*` globally (use `--success`/`--danger`/`--accent-text`), replace `tr:not([class*='bg-'])` with a row-state class, and give `.money`/`.seg` layout variants instead of per-container overrides.
**Risks:** visual regressions everywhere; do it screen by screen with screenshots in both themes.
**Scope:** in: tokens and views. Out: new features.
